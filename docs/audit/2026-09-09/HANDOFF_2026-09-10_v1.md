## 2. MoChA on 17p — the first work item (one session)

Why 17p only: catalog spacing is a median 715 kb between backbone tiles (no LD, phasing impossible),
27 kb on 17p (385 sites, 23 % of pairs within 20 kb). MoChA's phased-BAF advantage exists on 17p;
elsewhere BAF_V2 (unphased, arm-level) is the detector. Goal: low-fraction (≈2–5 %) 17p cnLOH / loss
as a seventh consensus arm **M**.

Inputs already in hand: per-sample `<sample>.allelicCounts.tsv` (GATK_CNV_CALLING.out.allelic;
staged in the CNV_BAF_CNLOH and CHROM_PAGES tasks), catalog `assets/twist_myeloid/snp_sites.baf.bed`,
`assets/twist_myeloid/baf_background.tsv`, denoised copy ratio.

Steps (each cold-startable):
1. **Reference haplotypes, chr17 only.** EBI is reachable (HTTP 200 today):
   `https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/data_collections/1000G_2504_high_coverage/working/20220422_3202_phased_SNV_INDEL_SV/`
   → `1kGP_high_coverage_Illumina.chr17.filtered.SNV_INDEL_SV_phased_panel.vcf.gz` (+ .tbi);
   store under `/goast/hemat_data/references/1000G_hg38_phased/`; optionally
   `bcftools view -R assets/twist_myeloid/snp_sites.baf.bed` to a chr17-sites subset for speed
   (keep the full chr17 file too; SHAPEIT5 phases better with the full panel).
2. **Container** `local/mocha:v1` (Dockerfile under `containers/mocha/`): bcftools 1.20 +
   `freeseek/mocha` plugin (bcftools +mocha, +extendFMT, +mochatools) + SHAPEIT5
   (`phase_common`). Build with `docker build --network=host`, export to the singularity cache as
   `local-mocha-v1.img`. Must stay Docker-runnable for clinical-23.
3. **Genotype VCF from allelic counts** — new `bin/baf_genotypes_vcf.py`: catalog sites on chr17,
   depth ≥ 20, GT by AF (≤ 0.15 hom-ref, ≥ 0.85 hom-alt, else het), FORMAT GT:AD:DP, REF/ALT from
   the catalog names (`het_chr17_<pos>_<REF><ALT>`), header contigs from the FASTA .fai. Check
   MoChA's documentation for the sequencing-input mode (AD-based BAF/LRR) before choosing FORMAT
   fields — I have not verified whether it needs BAF/LRR precomputed or derives them from AD.
4. **Phase** with `shapeit5 phase_common --input sample.vcf.gz --reference chr17.panel.vcf.gz
   --region chr17 --map <chr17 genetic map>` (map from the SHAPEIT5 resources; store beside the panel).
5. **Call**: `bcftools +mocha -g GRCh38 --input-stats/--calls/--ucsc-bed …` on the phased VCF with
   the LRR from the denoised copy ratio (or let MoChA compute from AD); keep chr17 only; parse the
   calls table (chrom, start, end, cell fraction, type: CNP/ Del / CN-LOH / Dup).
6. **Consensus arm M** in `bin/cnv_consensus_multi.py`: genes on 17p take M from the overlapping
   MoChA segment (LOSS / CNLOH / GAIN with cell fraction); tier rules: M + B agree → TIER_1;
   M alone at ≥ 5 % → TIER_2 with "phased BAF only" flag; document in
   `docs/sops/cnv_consensus_cmx_v2.md` (CMX_V2_5). Add `m_call`, `m_cf` columns; flags letter M.
7. **Module + wiring**: `modules/local/mocha_17p.nf` (container local/mocha:v1, inputs allelic +
   denoised + panel + map), called from `subworkflows/local/gatk_cnv_calling.nf` next to
   CNV_BAF_CNLOH; outputs joined into the CNV_CONSENSUS_MULTI tuple; publish to `<sample>/cnv_mocha/`;
   ORGANIZE copies the calls + phased-BAF plot into `clinical/cnv/mocha/`.
8. **Plot**: phased BAF along 17p (sign from the phased GT) as a fourth panel on the chr17
   chromosome page (`bin/plot_targets_trio.py`) or a small standalone PNG on the BAF sub-tab.
9. **Validation**: run8 (no 17p cnLOH among the eight; 26CGH1250 has 17p GAIN → MoChA should call
   a duplication at ~0.65 cell fraction) plus an in-silico dilution: take a diploid sample's chr17
   allelic counts and impose a cnLOH at 2, 5, 10 % by resampling ALT counts at het sites
   (`tools/patches/2026-09-10/simulate_17p_cnloh.py`), phase, call; report the detection floor.
   Resume cost: new process (8) + consensus + downstream, ~50 tasks.

Then, same day if time allows: **sub-arm segmentation (BAF_V2c)** — segment the mirrored deviations
plus depth along each chromosome (CBS-style on the unsigned d and the denoised log2), call segments
