## 2. Operating rules — additions

- Never write a placeholder such as <run8 outdir> into a command block; resolve it.
- Before any launch: `pgrep -u hemat -af "nextflow.*\.jar run"`; a second resume on the same
  session dies on the cache LOCK and writes its error into the shared log. `nextflow log <run>`
  also fails while a run is alive — use `grep -oE "Submitted process > [^ ]+" .nextflow.log`.
- Newest-by-mtime files under work/ are usually staged symlinks in a consumer task; find the
  producer with `find work -maxdepth 3 -type f -name …`; the reference is the -R argument in
  .command.sh, not a *.fa in the task directory.
- Console process names are abbreviated (`TSP…OTATE`).
